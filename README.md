# llm-fine-tuning-practice
About This Repository

This repository contains my hands-on exercises and modified implementations based on the short course Fine-Tuning for LLMs: From Beginner to Advanced by Axel Sirota. The original notebooks were adapted for independent practice, with changes to datasets, preprocessing, training configurations, evaluation methods, and explanatory documentation.

The repository is intended to demonstrate my practical understanding of transfer learning and language-model fine-tuning. Credit for the original course concepts and instructional structure belongs to the course author and provider.
